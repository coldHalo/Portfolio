# Portfolio

Webpage for my professional portfolio, made from scratch using HTML, CSS and JS. My domain provider is DigitalPlat, where I got a free domain for a year. I used cloudflare to get DNS records for my website to then connect to Vercel. Vercel automatically apply changes to my website via a GitHub repository (this one).
