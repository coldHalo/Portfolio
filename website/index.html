My Website Project

Summary of my Project

This project was for a college assignment, where we were tasked to make and show off a showreel and a portfolio to an employer. Many others went for a website builder or a powerpoint-like website, but I decided for the role I'm trying to go into I wanted to make a website completely from scratch. I decided against using React and Node.js as I wanted this to be as vanilla as possible without using any 3rd party libraries.

Hosting

I got my domain from a website called DigitalPlat, which gives you a free domain for a year when signing up. I decided to use the "dpdns.org" as it made the most sense.
